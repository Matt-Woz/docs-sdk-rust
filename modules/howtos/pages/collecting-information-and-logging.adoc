== Configuring Logging

The Couchbase {name-sdk} has no hard dependency on a specific logger implementation.
It uses the Rust https://docs.rs/log/latest/log/[log] facade and will use the logger that has been configured in the environment.
If no logger is configured then no logging will occur.

Rust has several logging implementations available including https://docs.rs/env_logger/latest/env_logger/[env_logger].
