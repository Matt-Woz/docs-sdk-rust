== Getting Started

Let's get started by connecting to a Couchbase cluster, as usual (of course, change the address and credentials to match your own cluster's):

[source,rust]
----
include::devguide:example$src/queries.rs[tag=connect,indent=0]
----

The examples below will use the travel-sample example bucket.
We will also be using the `airline` collection within the `inventory` scope in that bucket.
This can be installed through the Couchbase Admin UI in Settings -> Sample Buckets.

In order to be able to use query on a scope, it is best to at least have a primary index created.
The easiest way to create this is through the Couchbase Admin UI.
Simply visit the Query tab then write this in the Query Editor and hit Execute:

[source,n1ql]
----
CREATE PRIMARY INDEX ON `travel-sample`.`inventory`.`airline`
----
